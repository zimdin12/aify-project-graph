**And the false-positive half, found the same hour:** the only suite failure after

★ **The two failure modes are ONE cause, not two** (ef-manager): it asserts TEXT, and
text varies for reasons uncorrelated with behaviour — *in both directions*. So this is
not a weak test. **"A test with zero correlation to correctness is a random number
generator attached to your attention"**, and it costs the same attention whichever way
it fires.

### ★★ The three-layer pattern — a false positive DELETES a warning

Three independent instances in one day, which is a pattern claim rather than an
anecdote:

| layer | the false positive | the warning it deleted |
|---|---|---|
| the **field** | `tests_adjacent` listing a test on a `vec3` edge | suppressed `no_test_coverage` — the safety axis reported SAFE |
| the **tier** | `import_linked` claimed on a non-import edge | cleared `tests_unverified_for_symbol` on a borrowed warrant |
| the **test** | 68 cases that cannot fail for the right reason | suppress the no-coverage signal for the suite itself — they make it GREEN |

**Specimen to lead with:** `expect(src).toMatch(/… \/\/ and the file must not be
listed/)` — an assertion on a production comment, written the same day as the fix it
was meant to guard. Delete the predicate, keep the comment, green.

⇒ This is why source-grep tests are **worse than no tests**: no test claims nothing; a
test that cannot fail claims coverage.

## 4 — Make provenance travel with the value  ·  owner: graph-tech-lead

ef-manager's Q0, and the best structural result of the day. The rule form —
"state the population" — cannot work, and not for discipline reasons: **the person
stating the population is the person who already knows it.** You cannot notice an
assumption you are currently making. So the basis must be emitted by the CODE.

**We already shipped this, on exactly one number:**
`lspVerifiedPctDenominator: "verifiable_and_in_scope_calls"`.

**Generalise it: every emitted ratio carries a basis field.** Then the invalid
comparison becomes visibly invalid on the page to a reader who knows nothing about
extractor internals:

```
echoes   1.4%   basis: "no-generic-references (cpp.js:545)"
APG     14.6%   basis: "generic-identifier-references (generic.js:350)"
```

It stops being a judgement call and becomes a mismatched string.

**This is one principle with four existing rules:** *a caveat must be computed from
the same source as the number it qualifies* · *the server commit is an experimental
parameter* · *success must attest corpus and scope* · and this. All four say: **attach
provenance to the value so the value cannot travel without it.** A cross-population
error is a number that travelled into a comparison and left its denominator behind.

## The through-line

Nineteen defects this week reduce to one shape: **a stand-in accepted for the thing
itself.** A comment for a decision. Source text for behaviour. A file-level edge for a
symbol-level claim. `vec3` for the target symbol. A pre-filter snapshot for current
state. An unread field for a useful one. A rule for a remedy.

And the fix is the same each time, which is why section 4 is the load-bearing one:
**make the artifact carry what it is a stand-in for, so it cannot travel without it.**
Rules depend on remembering. Emitted provenance does not.
