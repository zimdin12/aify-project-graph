== Q2 is a file fingerprint stable across a comment-only edit? ==
  comment-only edit changes the fingerprint?         NO (correct)
  MUTATION CONTROL: renaming a function changes it?  YES (correct)
  ⇒ Without the mutation control, "comment edit does not change it" is also what a
    constant would report. The pair separates stable from dead.
